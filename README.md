# Auto Backup

Automatically archives scenes in your Unity project, protecting your work against unexpected crashes, freezes, and accidental overwrites.

---

## What It Does

Auto Backup runs quietly in Unity, creating timestamped scene backups whenever you save. It organizes backups cleanly by project name, scene name, date, and time, keeping your assets safe without interrupting your workflow.

### Key Features

* **Save Triggered Backups:** Automatically archives scenes whenever you save changes in Unity.
* **Per-Scene Cooldown:** Independent timers per scene prevent rapid saves from cluttering your backup folder.
* **Organized Storage:** Backups are sorted into structured folders by project name, scene name, and date.
* **Activity Log Viewer:** Scrollable in-window log showing backup timestamps and live status.
* **Custom Destination:** Easily change the backup destination folder to any local or external directory.

## How to Add to VCC (VRChat Creator Companion)

Open the repository listing and click "Add to VCC":  
https://kitsuneba.github.io/KitsuneBaTools/

Or add it manually:
1. Open **VRChat Creator Companion**.
2. Go to **Settings** > **Packages** > **Add Repository**.
3. Paste the listing URL:
   ```
   https://kitsuneba.github.io/KitsuneBaTools/index.json
   ```
4. Click **Add**.
